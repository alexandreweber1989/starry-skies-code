# Feature Planner Command

```
/feature <demanda>
```

## Exemplos

```
/feature "Importar membros via CSV/Excel"
/feature "Módulo Mídia: biblioteca + solicitações de arte"
/feature "Atos de Amor: dashboard doações + ficha assistidos"
/feature "Portal de notícias e avisos públicos"
/feature "Gamificação: jornada do membro + badges"
/feature "Bot WhatsApp: lembretes escala + aniversários"
/feature "Login email/senha além do Google"
```
